# To-Do List Application

A simple console-based To-Do List Application developed using Python.

## Objective

The objective of this project is to create a simple to-do list manager where users can add, view, and remove tasks.

## Features

* Add new tasks
* View all tasks
* Remove tasks
* Store tasks in a text file
* Load previously saved tasks when the application starts
* Handle invalid user input

## Technologies Used

* Python
* File Handling
* Lists
* String Manipulation

## Project Files

* `todo.py` - Main Python application
* `tasks.txt` - Stores tasks permanently
* `screenshots/` - Contains application testing screenshots

## How to Run

1. Open the project folder.
2. Run the `todo.py` file using Python.
3. Select an option from the menu:

   * 1 - View Tasks
   * 2 - Add Task
   * 3 - Remove Task
   * 4 - Exit

## Concepts Used

* Python Lists
* File Handling using `open()`
* `with` statement
* Functions
* Loops
* Conditional Statements
* Exception Handling
* String Manipulation using `.strip()`

## Outcome

A persistent command-line To-Do List Application that allows users to manage tasks and saves them in a text file so they remain available even after restarting the application.
